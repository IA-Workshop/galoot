## Lessons of the session worth keeping in mind

- Verification claims must name the exact revision they ran at; several implementers reported checks that were stale after a later commit (WU6a lint, plan 0012 lint).
- A label-only test run misses the cheap gates (markers, citations, golden check, trace); run those on every commit. Per P8 and P9, run the full suite only at the end of a test-and-code pair and the seven presets once at the final revision.
- Mutation drivers must not run CTest after a failed build in a tree whose programs they deleted: CTest 4.4 under the shared pool keeps a slot for a test whose program is missing (lesson 0063). The pool restarts (`tools/jobpool stop && tools/jobpool start 23`) happened four times on 2026-11-01 for this reason.
- A differential cost measurement can hide a one-time check present in both units (plan 0012 finding F1; knowledge-base note).
- Reviewers found real gaps in every unit (second-operand checks untested, public comments that overstated guarantees, tests that could not detect the defect they were written for). Keep the independent review.
