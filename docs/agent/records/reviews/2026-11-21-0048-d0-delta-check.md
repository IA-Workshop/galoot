### 5. Nit: the overflow range of `antigrade` is overstated

The README's first table and the note on row `bits.hpp:80-81` say that `static_cast<int>(n) - grade(a)` overflows "for n of 2^31 or more". Since C++20 the conversion is modular, so it overflows only when n mod 2^32 lies from 2^31 to 2^31 + grade(a) − 1. For example, n = 2^32 converts to 0 and does not overflow. The verdict, keep, is unaffected. Suggested wording: "for some n of 2^31 or more".

### 6. Nit: "eleven preconditions on public declarations" in the D4 row
